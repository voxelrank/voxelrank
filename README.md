### Hi, this is VoxelRank

[VoxelRank](https://voxelrank.com) is a free server list for Minecraft and 11 other games. Players vote, and the votes decide the ranking. Sponsored slots are always labelled and kept apart from it.

- Minecraft (Java, Bedrock, Eaglercraft), Hytale, Rust, ARK, FiveM, CS2, Valheim, Terraria, Palworld, DayZ and more
- 26 languages
- A vote-reward plugin for Spigot, Paper, Purpur and Folia (1.8.8+, Java 8+), plus NuVotifier v1/v2

**Repos**

- [voxelrank-minecraft-server-list](https://github.com/voxelrank/voxelrank-minecraft-server-list) – docs and setup guides for server owners

Own a server? [Add it here](https://voxelrank.com/add), it's free.
